# واجهات HTTP المحلية

تُخدم هذه النقاط من الهاتف أثناء تشغيل المشاركة. المسارات نسبية إلى الرابط المحلي الظاهر في التطبيق. لا يوجد تسجيل دخول داخل HTTP؛ لا تفتح الرابط إلا لأجهزة تثق بها على شبكة المشاركة، وأوقف الخادم بعد انتهاء النقل.

## صفحات وأصول القراءة

| الطريقة والمسار | الاستخدام والاستجابة |
| --- | --- |
| `GET /` | واجهة إدارة الملفات؛ HTML/CSS/JavaScript مضمّن |
| `GET /brand.png` | أيقونة التطبيق بصيغة PNG |
| `GET /icons/{name}.svg` | أيقونة محلية من الأصول المضمّنة؛ الاسم يقبل أحرفاً صغيرة وأرقاماً وشرطة فقط |
| `GET /api/info` | JSON: `upload`, `delete`, `free`, `total`, `root` |
| `GET /api/list?path={relativePath}` | JSON: `path`, `items`; كل عنصر يتضمن `name`, `dir`, `size`, `mtime`. ملفات APK قد تتضمن `applicationId`, `applicationLabel`, `appIconDataUrl` |
| `GET /f/{relativePath}` | تنزيل/معاينة ملف. يقبل `Range: bytes=...` ويعيد `206` و`Content-Range` عند قبول النطاق؛ `?dl=1` يطلب اسم تنزيل |
| `GET /api/zip?p={path}&p={path}` | تنزيل ملف أو عدة ملفات/مجلدات كأرشيف ZIP مبثوث |

يجب ترميز قيمة `path` في query string وترميز كل مقطع من المسار في `/f/`. يعيد `/api/list` العناصر المرئية فقط؛ العناصر التي تبدأ بنقطة والروابط الرمزية لا تظهر ولا تدخل في ZIP.

## عمليات التعديل

تُرسل الطلبات التالية باستخدام `POST` وجسم `application/x-www-form-urlencoded`، باستثناء الرفع المباشر. الاستجابة الناجحة JSON.

| المسار | الحقول | متطلبات الإعداد |
| --- | --- | --- |
| `/api/mkdir` | `path`, `name` | السماح بالرفع |
| `/api/delete` | `path` | السماح بالحذف |
| `/api/rename` | `path`, `name` | السماح بالحذف |
| `/api/upload?path=...&name=...` | جسم الملف الخام مع `Content-Type: application/octet-stream` و`Content-Length` | السماح بالرفع |

يرفض الخادم العمليات المعطّلة بإجابة `403`. المسار غير المسموح أو الرابط الرمزي يعيد `403`؛ العنصر غير الموجود `404`؛ البيانات أو الأسماء غير المقبولة `400`. ملفات الرفع المباشر تُكتب أولاً باسم مؤقت مخفي، ثم تُنقل إلى الاسم النهائي عند اكتمال النقل.

## صيغة طلبات للتطوير

```sh
curl "http://PHONE:8080/api/info"
curl --get --data-urlencode "path=folder" "http://PHONE:8080/api/list"
curl -X POST -d "path=folder&name=new-folder" "http://PHONE:8080/api/mkdir"
curl --get --data-urlencode "p=folder" "http://PHONE:8080/api/zip" -o folder.zip
```

استبدل `PHONE:8080` بعنوان IP والمنفذ اللذين يعرضهما التطبيق، ونفّذ الطلبات من جهاز متصل بشبكة المشاركة. أمثلة التعديل لا تعمل إذا عطّل المالك العملية المقابلة.

## قواعد التنفيذ

- جميع المسارات تمر عبر `resolve()` في `MyHttpServer`; لا تتجاوز هذه الدالة عند إضافة endpoint.
- لا تثق بواجهة المتصفح لإخفاء عمليات الرفع أو الحذف؛ يجب أن تبقى حماية العملية في الخادم.
- لا تضف نقطة نهاية خارج نطاق الشبكة المحلية أو ادعاءً بوجود TLS أو هوية مستخدم.
- عند تغيير مخطط الاستجابة أو أسماء المعاملات، حدّث هذا الملف وواجهة `WebUi.kt` معاً.
